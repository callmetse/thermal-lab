# 最小人工标注与现场验收

先用已有回放练习标注，再采室内目标场景。`data/labels_template.csv` 的空白栏需要人工填写；当前没有准确率标签。

## 怎么标

按源视频 SHA256、帧号／起止秒、人工人物编号与边框关联，不按模型预测 ID 直接认人。衣物写可见类别；完整衣着由当事人确认时另记，不从图片补内层。姿态看单帧，动作要看前后片段。静坐、站立、走动、坐下／站起、穿脱外套、遮挡、多人交叉、无人→入场都要覆盖。

多人场景至少区分近／中／远人物，并统计所有应识别人物的漏检，不能只给识别成功的框打标签。原始画面可标注的衣物细节与上传缩放后可辨识的细节也分别记录。

CLO/MET 参考填 `reference_kind`：`standard_reference` 或 `physical_measurement`。标准参考需记录表版本、完整衣着与具体任务／强度；物理测量需独立仪器或数据来源。不能将算法自己的查表值复制成“独立真值”。无数值依据就先只评价衣物／动作。

最终按人物／衣着／片段留出测试集，避免相邻帧一边调参一边验收。报告人物 P/R、服饰按类 F1、动作 macro-F1、未知率和全体目标上的有效正确覆盖；有独立数值参考后再算 CLO/MET MAE。

## 热点与 PC 断网

1. 另配相机或确认相机空闲后启用新项目采集；不要偷偷借旧项目图像通道。
2. Pi 接手机热点，确认 Pi/GPU 自己的 SSH 隧道存在。
3. 手机 SSH 转发 `28880`，打开新控制台；记录 run、网络和人物／衣着场景。
4. PC 断网或关机，在手机上启动／停止 A/B/C；录像留证，确认图像、事实、7B、日志持续更新。
5. 记录离线／恢复和真实变化延迟，候选默认档再跑长时稳定性。
