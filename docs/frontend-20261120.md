# Front-end experiment bench: what is deployed (2026-11-20)

The bench is the browser console served by Caddy on the Pi at `http://<pi>:28880`. It is a
single entry point in front of three backends:

| Route | Backend | Purpose |
|---|---|---|
| `/live-video`, `/api/preview*` | `127.0.0.1:28990` (vision-edge) | live preview and frame metadata |
| `/data`, `/api/video-uploads`, `/api/collection-batches*`, `/api/environment/*` | `127.0.0.1:28992` (data plane) | experiment batches, uploads, environment history |
| everything else (`/lab`, `/api/state`, `/api/start`, `/api/stop`, `/api/ack`) | `127.0.0.1:28881` via the console tunnel | Node-RED console on the control cloud (`:28880`) |

The route table is in the Pi's `deploy/console.Caddyfile`, archived at
`deployments/pi-20261120/abc20261102/deploy/console.Caddyfile`.

Reading:

- The repository's `page.html` and `flows.json` are **not** what the bench serves. Both the control
  host and the Pi carry the 35 KB page and the 53 KB flow file.
- The newest front-end artifact is the control host's `flows-native.json` (2026-11-17), almost
  10 KB larger than the repository copy — the repository's flow definition predates it.
- The data page (`data.html`) matches between the repository and the Pi and is served by the data
  plane; the control host does not hold a copy.
- `settings.js` matches between the repository and the control host; the Pi keeps an older,
  environment-driven 578-byte variant under `deploy/nodered/`.

## Archives

- `deployments/control-20261120/deploy/nodered/` — `flows.json`, `flows-native.json`, `page.html`,
  `settings.js`, plus the control host's systemd units, Caddyfile, compose files and bootstrap
  scripts (25 files).
- `deployments/pi-20261120/abc20261102/deploy/` — the LAN console configuration and the Pi's copy
  of `nodered/`.

Host addresses and account names were replaced with examples when archiving; Node-RED's runtime
credential secret file (`.config.runtime.json`) is not archived.

## Consequence for this repository

`vision/deploy/nodered/` is a historical copy. Before editing the bench, take the control host's
`flows-native.json` and the Pi's `data.html` as the current truth, and reconcile the differences
above rather than regenerating from the repository.
