# Front-end experiment bench: what is deployed (2026-11-20)

The bench is the browser console served by Caddy on the Pi at `http://<pi>:28880`. It is a
single entry point in front of three backends:

| Route | Backend | Purpose |
|---|---|---|
| `/live-video`, `/api/preview*` | `127.0.0.1:28990` (vision-edge) | live preview and frame metadata |
| `/data`, `/api/video-uploads`, `/api/collection-batches*`, `/api/environment/*` | `127.0.0.1:28992` (data plane) | experiment batches, uploads, environment history |
| everything else (`/lab`, `/api/state`, `/api/start`, `/api/stop`, `/api/ack`) | `127.0.0.1:28881` via the console tunnel | Node-RED console on the control cloud (`:28880`) |

The route table is in the Pi's `deploy/console.Caddyfile`, archived at
`sources/pi-20261120/abc20261102/deploy/console.Caddyfile`.

## Three copies of the front end

| File | Repository | Control cloud | Pi |
|---|---|---|---|
| `console.Caddyfile` | 756 B | 687 B (control-side console) | 1,7 KB (LAN entry, archived) |
| `nodered/flows-native.json` | 92,395 B | **102,105 B (2026-11-17 19:31)** | absent |
| `nodered/flows.json` | 66,051 B | 53,750 B | 53,750 B (same as control) |
| `nodered/page.html` | 51,882 B | 35,206 B | 35,206 B (same as control) |
| `nodered/settings.js` | 677 B | 677 B (same as repository) | 578 B (older variant) |
| `nodered/data.html` | 16,430 B | absent | 16,430 B (same as repository) |

Reading:

- The bench does not run the repository's `page.html`. The repository holds a **2026-11-16** local
  edit (51,882 B); both devices serve the **2026-11-03** page (35,206 B). Which one is intended has
  not been decided.
- `flows.json`: the deployed 53,750 B copy is dated 2026-11-02 20:14; the local source copy
  (66,051 B) is dated 21:46 the same day. The deployed file is the earlier same-day state.
- `flows-native.json`: the control host's copy is **newer and larger** — 2026-11-17 19:31 versus the
  local 2026-11-16 21:12 — so an edit exists on the control host that never came back into the
  source tree.
- `data.html` is identical in all three copies and is served by the Pi's data plane; the control
  host does not hold one.
- `settings.js` matches between the repository and the control host; the Pi keeps an older,
  environment-driven 578-byte variant under `deploy/nodered/`.

No single tree is authoritative for every front-end file: the page was edited locally without a
deployment, while the flow definition was edited on the control host without a copy-back.

## Archives

- `sources/control-20261120/deploy/nodered/` — `flows.json`, `flows-native.json`, `page.html`,
  `settings.js`, plus the control host's systemd units, Caddyfile, compose files and bootstrap
  scripts (25 files).
- `sources/pi-20261120/abc20261102/deploy/` — the LAN console configuration and the Pi's copy
  of `nodered/`.

Host addresses and account names were replaced with examples when archiving; Node-RED's runtime
credential secret file (`.config.runtime.json`) is not archived.

## Consequence for this repository

`vision/deploy/nodered/` is a working copy, not the deployed bench. Reconcile file by file before
editing: the page exists only in its 2026-11-03 device form, the flow definition exists in a newer
form on the control host, and `data.html` is identical everywhere. The archives under
`sources/` show what ran; this tree shows what was being edited locally.
